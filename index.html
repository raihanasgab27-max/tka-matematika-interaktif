Refleksi itu cermin. Geser, lihat, paham.

Materi pencerminan untuk TKA. Jangan hafalin rumus dulu — coba gerakin titik di bawah, lihat bayangannya bergerak seperti motion graphic.

Coba langsung ↓
Contoh cepat
A (3, 2)→A' (3, −2)
Cermin: sumbu-Xy jadi −y

Bayangan selalu sama jauh dari cermin, cuma beda sisi.

1. Konsep dalam 30 detik

Refleksi (pencerminan) memindahkan titik ke sisi lain cermin dengan jarak yang sama. Ukuran dan bentuk tidak berubah, posisi kiri-kanan / atas-bawah tertukar.

3 bagian yang selalu ada di soal: 1) Titik awal A(x,y) — posisi benda. 2) Cermin — garis/titik acuan (sumbu-X, sumbu-Y, y=x, dll). 3) Bayangan A'(x',y') — hasil. Cara baca soal: cari kata "dicerminkan terhadap ..." itu cerminnya, angka di depannya itu titik A.

Sifat wajib ingat

Jarak ke cermin sama • Garis AA' tegak lurus cermin • Bentuk tetap, orientasi berbalik. Artinya kalau A 2 kotak di atas sumbu-X, A' pasti 2 kotak di bawahnya.

Kapan dipakai? (ciri soal TKA)

Soal menyebut: "bayangan", "cermin", "lipatan", "danau / air sebagai cermin", "koordinat hasil pencerminan". Kalau ada denah + sumbu, hampir pasti refleksi.

2. Rumus + kapan dipakai

A(x,y) → A'(x',y'). Contoh pakai A(3,2) biar kebayang. Cara pakai: lihat cermin di soal → ambil rumus sebaris → ganti x,y dengan angka.

Sumbu-X (cermin datar)

(x, −y)

Contoh A(3,2):
1) Tulis x=3, y=2
2) x' = x → x'=3 (x tetap, panah lurus)
3) y' = −y → y'=−2 (y dibalik tanda, panah nyebrang)
→ A'(3,−2)

Kapan: atas-bawah terbalik / bayangan danau.

Sumbu-Y (cermin tegak)

(−x, y)

Contoh A(3,2):
1) x=3, y=2
2) x' = −x → x'=−3 (x dibalik)
3) y' = y → y'=2 (y tetap)
→ A'(−3,2)

Kapan: kiri-kanan terbalik / ngaca.

Garis y = x (diagonal /)

(y, x)

Contoh A(3,2):
1) x=3, y=2
2) x' = y → x'=2 (x diisi dari y)
3) y' = x → y'=3 (y diisi dari x)
→ A'(2,3) — tukar tempat.

Kapan: soal bilang "tukar koordinat".

Garis y = −x (diagonal \)

(−y, −x)

Contoh A(3,2):
1) x=3, y=2
2) x' = −y → x'=−2
3) y' = −x → y'=−3
→ A'(−2,−3) — tukar + negatif semua.

Kapan: jebakan TKA, cek tanda dua kali.

Titik O (0,0) (putar 180°)

(−x, −y)

Contoh A(3,2):
1) x=3, y=2
2) x' = −3
3) y' = −2
→ A'(−3,−2) — dua-duanya balik.

Kapan: soal "terhadap titik asal / O".

Garis x = h (cermin geser)

(2h−x, y)

Contoh h=1, A(3,2):
1) h=1, x=3, y=2
2) x' = 2×1−3 = −1 (x dihitung ulang)
3) y' = 2 (y tetap)
→ A'(−1,2).

Kapan: pintu lipat / garis x=2.

4. Contoh dasar (mekanik)

Pola pengerjaan selalu sama: 1) tulis A dan cermin, 2) ambil rumus, 3) substitusi. Contoh:

A(2,3) → sumbu-X?

Rumus (x,−y) → Jawab: (2,−3). y jadi negatif, x tetap.

B(−1,4) → sumbu-Y?

Rumus (−x,y) → Jawab: (1,4). x jadi positif, y tetap.

C(5,1) → y=x?

Rumus (y,x) → Jawab: (1,5). x dan y tukar tempat.

5. Soal cerita numerasi (model TKA)

Di TKA jarang keluar "hitung (2,3) → ...". Yang keluar cerita. Kuncinya: ubah cerita jadi A + cermin dulu, baru hitung.

Cerita 1 — Layang-layang di danau

Layang-layang di titik (4,5). Permukaan danau sebagai sumbu-X. Di mana bayangannya?
Langkah: A=(4,5), cermin=sumbu-X → rumus (x,−y) → (4,−5). Jawab: (4,−5) — sama jauh, di bawah air.

Cerita 2 — Denah kamar lipat

Denah dilipat sepanjang garis x=2 (pintu lipat). Stiker di (5,1) jatuh ke seberang lipatan. Posisi baru?
Langkah: A=(5,1), h=2 → rumus (2h−x,y) = (4−5,1) = (−1+? hitung: 4−5=−1) → (−1,1). Jarak ke garis lipat: |5−2|=3, bayangan 3 kotak di sisi lain.

Cerita 3 — Cermin diagonal taman

Jalur taman y=x jadi cermin. Lampu di (2,6) memantul. Titik pantulnya?
Langkah: A=(2,6), cermin y=x → tukar → (6,2). Tips: kalau x<y, bayangan jadi x>y — wajar karena nyebrang diagonal.
